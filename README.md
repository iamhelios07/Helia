## What is Helia?

**Helia** is a highly customizable, open-source AI application designed specifically for immersive roleplaying games, powered by your own API key.

This project builds upon the spirit of RisuAI while taking a different approach to roleplaying experiences.

RisuAI has long enabled immersive gaming experiences through its built-in CBS, Lua scripting, Plugin API, and other extensibility features. However, these systems have inherent limitations when it comes to building fully customized games.

Helia aims to overcome these limitations by prioritizing game creation and the player experience over the flexibility of general-purpose roleplaying. It empowers creators to bring their unique game ideas to life with as few technical constraints as possible, while providing players with a seamless and intuitive gaming experience.
