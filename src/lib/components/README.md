# 항목 이름 변경과 삭제

항목 조작 UI는 아래 컴포넌트를 공통으로 사용합니다.

- `ItemActions`: 목록 행의 `⋯` 메뉴. 이름 변경·삭제 순서와 아이콘을 통일합니다.
- `ItemActionButton`: 메뉴 항목과 설정 폼의 공통 버튼. 이름 변경·삭제는 `action`, 진입점 지정 같은 다른 작업은 `icon`과 `text`를 전달합니다. 공간이 좁을 때는 `compact`를 사용합니다.
- `NameDialog`: 이름 입력, 검증 오류, 저장 중 상태, 취소와 키보드 포커스를 처리합니다.
- `ConfirmDialog`: 대상과 삭제 범위를 안내합니다. 삭제는 `danger`, 일반 변경 확인은 `default` 색상을 사용합니다.

실제 저장·삭제 규칙은 호출하는 화면이나 도메인 모듈에서 처리합니다. 삭제할 수 없는 항목은 `deleteReason`으로 이유를 표시합니다. 목록의 이름 변경은 `onrenamevalue`, 별도의 경로 처리가 필요한 경우에는 `onrename`으로 공통 입력 창을 연결합니다. 기존 설정 폼에서 이름 필드를 편집하는 기능은 폼 저장 흐름을 따릅니다.

추가 메뉴 항목은 `ItemActions`의 `actions`로 전달합니다. 모든 항목에 `id`, `icon`, `text`, `onclick`을 지정해야 하며, 메뉴 안에 개별 HTML 버튼을 직접 넣지 않습니다. 작업 메뉴는 항상 아이콘과 글씨를 함께 표시합니다.
